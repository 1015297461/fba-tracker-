一、系统概述
产品开发全流程管理系统是一个面向 Amazon FBA 卖家的产品开发管理工具，采用单文件 HTML 实现，覆盖从选品立项到出货复盘的全流程管理。系统无需服务器，支持数据内嵌独立分享，接收方打开即可查看完整数据。

3.4 BOM 成本拆解
10 个预设组件分类：面料/布料、电机/马达、电源/电池、开关/控制、LED/灯珠、模具/外壳、包装材料、认证费、物流/运费、其他
每个组件：名称 + 规格/型号 + 分类（下拉选择）+ 用量/件 + 单价($) → 自动计算小计
BOM 合计行自动汇总所有组件成本
SVG 环形饼图：以利润测算「产品成本」为分母，BOM 合计为分子，灰色&quot;未拆解&quot;扇区显示覆盖缺口
水平条形图：按分类汇总，显示金额和百分比
图表标题显示 BOM 覆盖率（如&quot;BOM覆盖 88%&quot;）
🔄 同步按钮：BOM 合计一键填入利润测算的产品成本字段
成本敏感性分析：取 Top 5 高成本组件，滑块调整 ±50%，实时重算净利润变化
3.5 利润测算
利润计算公式如下：
毛利润 = 目标售价 - 产品成本 - 头程运费 - FBA费用
净利润 = 毛利润 - 平台佣金（售价×%）- 广告预算（售价×%）- 其他费用
净利率 = 净利润 ÷ 目标售价 × 100%
净利率颜色：≥20% 绿色 / 10%~20% 橙色 / &lt;10% 红色
BOM 参考成本行：显示当前 BOM 合计，点击 🔄 同步按钮自动填入产品成本
立项决策记录：通过立项 / 暂缓观察 / 否决 + 决策日期 + 备注
3.6 供应商管理
自定义添加多个供应商，对比报价
每个供应商：名称、联系方式、报价($/件)、MOQ、生产周期(天)
自动评分算法：基于价格/MOQ/周期的加权评分（100分制）
选定供应商：单选切换，确定最终合作方
最终确认备注：账期/质保/包装要求等
