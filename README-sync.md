# FBA Tracker · 局域网协作指南

## 单机使用（默认）
直接用任何静态服务器或双击离线版 `FBA-Tracker.html` 即可。所有数据保存在浏览器的 localStorage 中，不同浏览器/设备互相隔离。

## 局域网多人协作

### 1. 启动协作服务器（仅一人执行）
在项目根目录运行：
```bash
python3 server.py
```
看到下面的输出说明启动成功：
```
──────────────────────────────────────
  FBA Tracker 协作服务器已启动
──────────────────────────────────────
  本机访问：  http://localhost:8000
  局域网访问：http://192.168.x.x:8000
  数据文件：  /path/to/fba-data.json
──────────────────────────────────────
```

参数：
- `--port 9000` 改端口
- `--data /path/data.json` 自定义数据文件位置
- `--host 127.0.0.1` 限制只本机访问（不开放给同事）

### 2. 分享地址给同事
把 **局域网地址**（如 `http://192.168.1.42:8000`）发给同事，他们用 Chrome / Edge / Safari 打开即可。

> 同事的电脑必须和你处于**同一局域网**（同一 WiFi / 公司内网 / VPN）。

### 3. 看顶栏的同步状态
- ☁ **已同步 v123** — 一切正常，4 秒轮询一次，编辑后 600ms 自动推送
- ☁ **同步中...** — 正在保存到服务器
- ⚠ **已自动合并** — 你的修改和别人的同时落地，系统已用服务器版本覆盖你的本地视图（你的输入正在编辑的字段会保留，已提交的改动可能被覆盖）
- ⚠ **离线 (本地缓存)** — 网络异常，编辑暂存浏览器，恢复后自动重传
- 💾 **本地已保存** — 没探测到服务器，回退到纯 localStorage 模式（不与他人同步）

### 4. 数据备份
`fba-data.json` 就是全部数据。**建议每天 `cp fba-data.json fba-data-$(date +%F).json` 备份一次**，或者放在 Dropbox / 共享盘里自动同步。

### 5. 防火墙
启动失败 / 同事打不开？检查：

**macOS**：系统设置 → 网络 → 防火墙 → 允许 Python 接收入站连接

**Windows**：第一次运行时会弹防火墙询问，勾选"专用网络"和"公用网络"

**Linux**：`sudo ufw allow 8000/tcp`

### 6. 协作机制 & 局限

实现细节（一句话）：
- 客户端每 4 秒拉取一次服务器的 `version` 编号
- 客户端每次编辑后 600ms 防抖 PUT，附带 `baseVersion`
- 服务器用乐观锁：`baseVersion` 不等于当前版本 → 返回 409 + 最新数据，客户端自动覆盖
- 数据原子写入 `fba-data.json.tmp` 再 rename，避免半截写入

**适合**：3-10 人小团队、大家通常编辑**不同的产品** / 不同的字段。

**不适合**：两个人**同时改同一个字段** —— 后写的人会赢，先写的人改动会被回滚。如果你们经常会撞车，建议约定"谁负责哪几个 SKU"。

## 关机后数据会丢吗？
不会。`fba-data.json` 是磁盘文件。下次启动 `server.py` 会自动读取，版本号继续递增。

## 想退回单机模式？
把 `server.py` 停掉，刷新页面，前端探测不到 `/api/products` 就会回到纯 localStorage 模式。
