# FBA Tracker · 局域网协作指南

## 1. 启动

首次使用需要安装依赖并构建一次前端：
```bash
npm install
npm run build      # esbuild 把 src/ 打包为 compiled/bundle.js
```

之后启动服务器：
```bash
python3 server.py
```
（或者直接 `npm start`，会自动先构建再启动）

看到下面的输出说明启动成功：
```
──────────────────────────────────────────────────────────
  FBA Tracker 协作服务器 v2 已启动
──────────────────────────────────────────────────────────
  本机访问：  http://localhost:8002
  固定地址：  http://你的电脑名.local:8002  ← 换 WiFi 也不变
  当前 IP：   http://192.168.x.x:8002
  数据库：    /path/to/fba-data.db
  用户配置：  /path/to/fba-users.json
  当前版本：  v123  (7 个产品)
──────────────────────────────────────────────────────────
```

参数：
- `--port 9000` 改端口（默认 8002）
- `--db /path/fba.db` 自定义数据库路径（默认 ./fba-data.db）
- `--users /path/u.json` 自定义用户配置（默认 ./fba-users.json）
- `--host 127.0.0.1` 限制只本机访问（不开放给同事）

## 2. 登录

首次启动会自动创建 `fba-users.json`，默认账号：
- `admin` / `fba2025`（管理员）
- `editor` / `fba2025`（编辑员）

**请尽快修改默认密码**（直接编辑 `fba-users.json`，该文件不纳入 git 版本控制）。

## 3. 分享地址给同事
把**固定地址**（如 `http://你的电脑名.local:8002`）或**局域网 IP 地址**发给同事，他们用 Chrome / Edge / Safari 打开，用各自账号登录即可。

> 同事的电脑必须和你处于**同一局域网**（同一 WiFi / 公司内网 / VPN）。

## 4. 看顶栏的同步状态
- ☁ **已同步 14:32:05** — 一切正常，4 秒轮询一次，编辑后 600ms 自动推送
- ☁ **同步中...** — 正在保存到服务器
- ⚠ **已自动合并** — 你的修改和别人的同时落地，系统已用服务器版本覆盖你的本地视图（你正在编辑的字段会保留，已提交的改动可能被覆盖）
- ⚠ **离线 (本地缓存)** — 网络异常，编辑暂存浏览器，恢复后自动重传
- 💾 **本地已保存** — 没探测到服务器，回退到纯 localStorage 模式（不与他人同步）

## 5. 数据备份
所有数据存储在 SQLite 数据库 `fba-data.db` 中（同目录的 `fba-data.db-wal`/`fba-data.db-shm` 是运行期临时文件，正常现象）。

**建议定期备份**（服务器停止后再复制更安全）：
```bash
cp fba-data.db fba-data-$(date +%F).db
```

## 6. 防火墙
启动失败 / 同事打不开？检查：

**macOS**：系统设置 → 网络 → 防火墙 → 允许 Python 接收入站连接

**Windows**：第一次运行时会弹防火墙询问，勾选"专用网络"和"公用网络"

**Linux**：`sudo ufw allow 8002/tcp`

## 7. 协作机制 & 局限

实现细节（一句话）：
- 客户端每 4 秒拉取一次服务器的 `version` 编号
- 客户端每次编辑后 600ms 防抖 PUT，附带 `baseVersion`
- 服务器用乐观锁：`baseVersion` 不等于当前版本 → 返回 409 + 最新数据，客户端自动覆盖

**适合**：3-10 人小团队、大家通常编辑**不同的产品** / 不同的字段。

**不适合**：两个人**同时改同一个字段** —— 后写的人会赢，先写的人改动会被回滚。如果你们经常会撞车，建议约定"谁负责哪几个 SKU"。

## 8. 工具模块（关键词排名 / 产品采集）
"产品采集"解析商品详情页依赖 `beautifulsoup4`（可选 `lxml` 加速）：
```bash
pip3 install beautifulsoup4
```
未安装时不影响 FBA Tracker 其余功能，"产品采集"会把每个 ASIN 标记为采集失败并提示缺依赖。"关键词排名"基于正则解析，无需此依赖。

## 9. 想退回单机模式？
把 `server.py` 停掉，刷新页面，前端探测不到 `/api/products` 就会回到纯 localStorage 模式。
